## 3. 活体检测专项

### 3.1 正式活体

1. “考勤打卡”点击“开始活体打卡”。
2. 页面显示 3 组随机动作，动作池为：左移、右移、靠近、远离、点头、眨眼、张嘴、左转头、右转头、随机打光。
3. 每组只做当前动作，5 秒内完成。
4. 当前组通过后自动进入下一组。
5. 最终显示活体原因和分数。

**核心话术：** 单组通过只用于进入下一组；正式考勤时后端还会对全部帧重新复核。

### 3.2 每个挑战怎么判

| 动作 | 后端判定依据 |
|---|---|
| 向左/向右 | 人脸中心 `cx` 前后位移 |
| 靠近/远离 | 人脸框面积 `area` 前后比例 |
| 点头 | 人脸中心 `cy` 范围或净位移 |
| 眨眼 | `eye_dark`、`closed_eye_proxy`、短时闭眼峰值；前端 70ms 高帧率采样 |
| 张嘴 | `mouth_open`、`mouth_dark`、`mouth_edge` |
| 左/右转头 | `yaw_proxy`、`face_aspect`、横向位移 |
| 随机打光 | 人脸 RGB/亮度/色度变化与 session 随机颜色序列同步 |

### 3.3 照片/视频攻击自测

| 按钮 | 模拟攻击 | 预期 |
|---|---|---|
| 运行静态照片攻击自测 | 当前摄像头一帧复制为多阶段重复帧 | 拒绝，重复帧/动作不足 |
| 无摄像头样本攻击自测 | 库内样本复制为重复帧 | 拒绝，摄像头异常时兜底 |
| 举照片移动攻击自测 | 构造平面照片位置变化 | 拒绝，归一化人脸几乎刚性不变 |
| 预录视频攻击自测 | 动作看似正确但不响应本次随机闪光 | 拒绝，随机闪光响应不同步 |
| 展示随机挑战抗视频 | 展示 10 种动作、3 组、720 种组合、4 段闪光、90 秒过期 | 解释预录视频无法提前覆盖 |

## 9. 现场兜底

- 摄像头失败：用“无摄像头样本攻击自测”证明照片攻击被拒绝；用合照和报告展示其他功能。
- 情绪模型异常：打开验收清单看情绪诊断，说明自动回退 DeepFace/启发式。
- 合照现场跑慢：直接展示 10 人/50 人 JSON 报告。
- 隐私追问：公开仓库不上传真实 `storage/` 和 `data/app.db`，本地用老师授权 `face_data`。
